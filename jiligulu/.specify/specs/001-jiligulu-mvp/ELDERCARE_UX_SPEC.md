## 一、设计哲学

> **不做"老年模式"——默认就是最好的设计。** 老年人不想被标记为特殊群体。

核心原则：
1. **能少一个按钮就少一个按钮**
2. **语音优先，文字辅助**
3. **永远鼓励，绝不惩罚**
4. **子女远程可控**

## 二、配色体系

```
主色调：
  鹦鹉绿    #1A8A7D   — 主按钮、标题、品牌色
  暖橙      #F5A623   — 强调、成就、奖励
  深蓝灰    #1B2D45   — 正文文字

辅助色：
  浅绿背景   #F0FAF8   — 页面背景
  米白      #FDFBF7   — 卡片背景
  暖灰      #8E9AAF   — 次要文字
  
功能色：
  成功绿    #27AE60   — 学对了（但不用红色表示错误！）
  柔橙      #F5A623   — 温和提示（代替红色警告）

禁止使用：
  ❌ 红色作为错误/警告色（老年人看到红色=出错=焦虑）
  ❌ 纯白背景 #FFFFFF（刺眼）
  ❌ 低对比度文字（灰色文字在浅色背景上）
```

### 对比度要求

- 正文文字与背景对比度 ≥ 7:1（WCAG AAA级）
- 按钮文字与按钮背景对比度 ≥ 4.5:1
- 所有重要信息不能仅靠颜色区分（需配合图标/文字）

## 三、字体与字号

```
字号层级：
  特大标题    32sp    — 页面标题（"开始聊天"）
  大标题      28sp    — 场景名称
  正文        22sp    — 主要内容文字
  辅助文字    18sp    — 最小允许字号（次要信息）
  
  ❌ 禁止使用 16sp 以下字号

字体选择：
  中文：系统默认（iOS: PingFang SC, Android: Noto Sans CJK）
  英文：系统默认（圆润易读）
  
字重：
  标题: Bold (700)
  正文: Regular (400)
  强调: Medium (500) — 不使用斜体（老年人难以辨认）

行高：
  正文行高: 1.6（比标准1.4-1.5更宽松）
  段间距: 16px
```

## 四、触控与交互

### 4.1 触控目标

```
最小触控区域: 48 × 48 dp（WCAG标准44dp，我们更宽松）
推荐触控区域: 56 × 56 dp

按钮间距: ≥ 16dp（防止误触）
核心操作按钮: ≥ 64 × 64 dp（如"开始聊天"按钮）
```

### 4.2 手势设计

```
✅ 允许的手势:
  - 点击（tap）— 唯一核心手势
  - 长按说话（press and hold）— 语音输入
  - 上下滑动（scroll）— 浏览内容

❌ 禁止的手势:
  - 双击
  - 双指缩放
  - 左右滑动切换页面
  - 拖拽
  
老年人手指特点:
  - 手指粗，需要更大触控区域
  - 手指干燥，触屏可能不灵敏 → 按钮需要视觉反馈+音效反馈
  - 手抖，需要防抖处理（同一按钮300ms内的重复点击忽略）
```

### 4.3 按钮反馈

每个可交互元素必须提供：
1. **视觉反馈**：按下时颜色变深/缩放动画
2. **触觉反馈**：轻微震动（haptic feedback）
3. **音效反馈**（可选）：柔和的点击音

## 六、导航设计

### 6.1 底部导航栏（最多3项）

```
Tab 1: 首页 🏠    — 鹦鹉 + 开始聊天 + 学习统计
Tab 2: 叽叽 🐦    — 鹦鹉状态 + 成长 + 里程碑
Tab 3: 家人 👨‍👩‍👧   — 子女模式切换入口（需密码/指纹）
```

### 6.2 子女端切换

```
"家人"tab → 输入简单密码(4位数字) → 进入子女仪表盘
  ├── 学习报告（本周/本月/全部）
  ├── 场景管理（解锁/赠送场景包）
  ├── 设置（学习目标/提醒时间/账号管理）
  └── 分享中心（生成分享卡片）
```

## 七、动画与反馈

### 7.1 鹦鹉动画规格

| 状态 | 动画描述 | 帧数 | 循环 |
|------|---------|------|------|
| 睡觉 | 闭眼打呼，小气泡 | 60帧 | 循环 |
| 醒来 | 睁眼+伸懒腰+扑翅膀 | 30帧 | 单次 |
| 教学 | 歪头+嘴巴动 | 24帧 | 循环(说话时) |
| 开心 | 跳起来+翅膀拍拍 | 24帧 | 单次 |
| 鼓励 | 拍翅膀+点头 | 18帧 | 单次 |
| 思考 | 歪头+眨眼 | 30帧 | 循环(等待时) |
| 再见 | 挥翅膀+飞回窝 | 36帧 | 单次 |

**技术方案**：Rive（支持状态机，运行时动态切换）或Lottie（JSON动画，体积小）。

### 7.2 页面过渡

- 所有页面切换使用淡入淡出（200ms），不使用滑动切换
- 加载状态用鹦鹉思考动画替代loading spinner
- 操作成功用鹦鹉开心动画替代toast提示

## 八、无障碍（Accessibility）

```
✅ 必须支持：
  - 系统字号放大（支持到200%）
  - 屏幕阅读器（VoiceOver/TalkBack）标注
  - 高对比度模式
  - 音量增强选项（+3dB ~ +6dB）
  
⚠️ 考虑支持：
  - 字幕字号可调（提供3档：标准/大/特大）
  - 语速可调（提供3档：慢/标准/快，默认"慢"）
  - 触控灵敏度可调
```
