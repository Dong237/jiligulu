## 一、双角色架构

App内含两套界面，通过密码切换：

```
叽里咕噜 App
├── 👴 老人端（默认）
│   ├── 首页（鹦鹉 + 开始聊天）
│   ├── 语音对话页
│   ├── 复习卡片
│   ├── 场景选择
│   └── 叽叽状态页（鹦鹉成长）
│
└── 👩 子女端（密码切换）
    ├── 仪表盘（学习概览）
    ├── 学习报告（周报/月报）
    ├── 场景管理（解锁/赠送）
    ├── 设置（目标/提醒/账号）
    └── 分享中心
```

## 二、老人端页面结构

### 2.1 页面地图

```
[底部Tab导航 — 仅3个Tab]

Tab 1: 首页 🏠
  └── 开始聊天 → 语音对话页
  └── 今日复习 → 复习卡片列表
  └── 学习统计（迷你版，今日/本周数据）

Tab 2: 场景 📚  
  └── 场景包列表
      └── 场景详情 → 开始该场景对话

Tab 3: 叽叽 🐦
  └── 叽叽当前状态
  └── 成长历程
  └── 里程碑墙
  └── [家人入口] → 输入密码 → 子女端
```

### 2.2 核心用户流程

#### Flow 1: 首次使用（子女帮设置）

```
子女下载App
  → 子女注册（手机号+验证码）
  → 填写父母信息（称呼/性别/学习动机）
  → 选择学习目标（旅游/探亲/兴趣）
  → 生成父母专属登录二维码
  → 父母扫码 → 自动登录 → 引导对话（叽叽自我介绍）
```

#### Flow 2: 日常学习（老人端）

```
打开App
  → 看到叽叽醒来打招呼
  → 点击"开始聊天"
  → [可选] 选择今日场景（或使用推荐场景）
  → 进入语音对话（5-8分钟）
  → 对话结束 → 显示学习总结
  → 生成复习卡片
  → [可选] 分享到微信
  → 返回首页（叽叽回窝睡觉）
```

#### Flow 3: 子女查看进展

```
打开App → 切换到"叽叽"Tab
  → 点击"家人" → 输入4位密码
  → 子女仪表盘
      → 查看本周学习报告
      → 一键分享到朋友圈
      → [可选] 赠送新场景包
```

#### Flow 4: 从推送进入

```
收到推送："阿姨！叽叽想和你练练昨天学的 How much"
  → 点击推送
  → 直接进入语音对话页（跳过首页）
  → 自动开始昨天的复习场景
```

## 四、状态与错误处理

### 4.1 网络状态

| 状态 | 老人端显示 | 说明 |
|------|----------|------|
| 在线 | 正常显示 | — |
| 弱网 | "叽叽在努力连接中..." + 鹦鹉转圈动画 | 不显示技术错误信息 |
| 离线 | "叽叽休息了，先看看复习卡片吧" + 引导到离线可用的复习功能 | 复习卡片本地缓存 |

### 4.2 对话异常

| 异常 | 处理 | 用户感知 |
|------|------|---------|
| ASR失败 | 重试1次 → 播放兜底语音 | "叽叽没听清，阿姨再说一遍？" |
| LLM超时 | 播放思考动画 → 重试 → 备用LLM | "嗯...叽叽想想..." |
| TTS失败 | 显示文字回复 | 文字正常显示，语音缺失 |
| 全部失败 | 友好提示 + 建议稍后再试 | "叽叽累了需要休息一下" |

## 六、推送通知架构

### 6.1 通知类型

| 类型 | 接收者 | 频率 | 示例 |
|------|--------|------|------|
| 每日邀约 | 老人 | 1次/天 | "阿姨早上好！叽叽想和你聊聊" |
| 连续打卡 | 老人 | 达成时 | "连续学习7天！叽叽长出新羽毛了" |
| 周报 | 子女 | 1次/周 | "妈妈这周学了23个新词！点击查看" |
| 里程碑 | 子女 | 达成时 | "恭喜！妈妈已经学了100个表达" |
| 回流 | 老人 | 3天未登录 | "阿姨好久不见！叽叽在等你呢" |

### 6.2 推送策略

```python
PUSH_STRATEGY = {
    "daily_invitation": {
        "default_time": "09:30",
        "adapt_to_user": True,       # 根据用户活跃时间自动调整
        "max_per_day": 1,
        "content_type": "personalized",  # 包含用户昨天学的内容
        "respect_dnd": True,
    },
    "weekly_report_to_child": {
        "day": "sunday",
        "time": "20:00",             # 周日晚8点，子女有空看
        "include_share_card": True,
    },
    "comeback": {
        "trigger": "3_days_inactive",
        "max_attempts": 3,           # 最多发3次回流通知
        "interval_days": [3, 7, 14], # 3天、7天、14天各一次
        "tone": "warm_not_guilty",   # 温暖但不绑架
    }
}
```
